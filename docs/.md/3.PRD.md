# PRODUCT REQUIREMENTS DOCUMENT

## CWS Penyuluh

### 1. Informasi Dokumen

Nama Produk: CWS Penyuluh

Jenis Produk: Sistem Informasi Penyuluhan Pertanian Berbasis Web

Lokasi Implementasi: Kabupaten Garut

Jumlah BPP: 42 BPP

Framework Utama: Laravel

Database: MySQL

Frontend: Laravel Blade

Status Dokumen: Draft PRD Versi Awal

### 2. Ringkasan Produk

CWS Penyuluh adalah sistem informasi berbasis web yang dikembangkan untuk membantu proses pengelolaan informasi BPP dan pelaporan penyuluh pertanian di Kabupaten Garut.

Sistem akan digunakan oleh 42 BPP dan CWS Pusat.

Fokus utama sistem adalah menggantikan proses pengumpulan laporan yang sebelumnya menggunakan Google Form dan Spreadsheet.

Melalui sistem ini, setiap BPP dapat login menggunakan akun masing-masing, melihat daftar penyuluh, mengetahui penyuluh yang sudah atau belum mengirim laporan, mengupload laporan, melakukan revisi, dan melihat hasil validasi dari CWS Pusat.

CWS Pusat dapat memantau seluruh proses pengumpulan laporan melalui dashboard terpusat.

Sistem juga menyediakan website publik untuk menampilkan informasi CWS Penyuluh, data BPP, informasi penyuluh, berita, video YouTube, video Google Drive, dan informasi kontak.

### 3. Latar Belakang Produk

Proses pelaporan penyuluh saat ini masih menggunakan Google Form dan Spreadsheet.

Proses tersebut menimbulkan beberapa kendala.

File laporan dapat tertukar.

Data pada Spreadsheet berpotensi tertimpa.

Monitoring penyuluh yang sudah dan belum mengirim laporan sulit dilakukan.

Riwayat laporan sulit dicari.

Riwayat revisi tidak tersimpan dengan baik.

Validasi laporan belum berada dalam satu sistem.

Data laporan dari banyak BPP tidak memiliki pengelolaan terpusat.

CWS Penyuluh dikembangkan untuk menyelesaikan permasalahan tersebut melalui sistem pelaporan yang terstruktur.

### 4. Tujuan Produk

Produk dikembangkan untuk:

1. Mempermudah BPP mengirim laporan penyuluh.

2. Mempermudah CWS Pusat memonitor laporan seluruh BPP.

3. Menampilkan penyuluh yang sudah dan belum mengirim laporan.

4. Menyediakan proses validasi laporan.

5. Menyediakan mekanisme revisi laporan.

6. Menyimpan setiap versi laporan.

7. Mencegah file laporan tertimpa.

8. Menyediakan arsip laporan berdasarkan penyuluh, BPP, periode, dan jenis laporan.

9. Mengurangi penggunaan Google Form dan Spreadsheet dalam proses pelaporan.

10. Menyediakan informasi BPP dan penyuluh secara terpusat.

11. Menyediakan media publikasi berita.

12. Menyediakan media publikasi video.

13. Menyediakan website informasi yang dapat diakses masyarakat.

### 39. Business Rules

BR-01

Setiap penyuluh harus terhubung dengan satu BPP aktif.

BR-02

Akun BPP hanya boleh mengakses penyuluh pada BPP sendiri.

BR-03

Laporan harus terhubung dengan penyuluh, BPP, dan permintaan laporan.

BR-04

Setiap revisi menghasilkan versi laporan baru.

BR-05

Versi laporan lama tidak boleh dihapus ketika revisi dikirim.

BR-06

Hanya Admin CWS yang dapat melakukan validasi laporan.

BR-07

Berita yang dikirim BPP tidak langsung tampil di website publik.

BR-08

Berita harus mendapatkan persetujuan Admin CWS sebelum dipublikasikan.

BR-09

Admin CWS memiliki akses ke seluruh BPP.

BR-10

Pengunjung tidak dapat mengakses halaman administrasi.

BR-11

Data pribadi penyuluh yang ditampilkan ke publik harus mengikuti persetujuan client.

BR-12

File laporan tidak boleh dapat diakses melalui URL publik tanpa pemeriksaan hak akses.

BR-13

Video hanya tampil pada website publik jika berstatus aktif atau dipublikasikan.

BR-14

Video Google Drive dibuka melalui link eksternal.

BR-15

Link Google Drive harus valid sebelum disimpan.

BR-16

Video Google Drive harus menggunakan pengaturan akses yang memungkinkan pengguna membuka file.

BR-17

Admin CWS memiliki hak mengelola seluruh data video.

### 48. Acceptance Criteria Utama

AC-01

Ketika akun BPP login, sistem hanya menampilkan data penyuluh dari BPP tersebut.

AC-02

Ketika Admin CWS membuat permintaan laporan, akun BPP dapat melihat permintaan tersebut.

AC-03

Sistem dapat menunjukkan penyuluh yang belum mengirim laporan.

AC-04

BPP dapat mengupload laporan atas nama penyuluh.

AC-05

Setelah laporan dikirim, status berubah menjadi Menunggu Validasi.

AC-06

Admin CWS dapat memberikan status Disetujui, Perlu Revisi, atau Ditolak.

AC-07

Jika laporan memerlukan revisi, BPP dapat melihat catatan admin.

AC-08

Ketika revisi dikirim, sistem membuat versi baru tanpa menghapus file sebelumnya.

AC-09

Admin dapat melihat progress pengumpulan setiap BPP.

AC-10

BPP tidak dapat mengakses laporan BPP lain.

AC-11

Berita yang belum disetujui tidak tampil pada website publik.

AC-12

Pengunjung tidak dapat mengakses dashboard BPP atau Admin CWS.

AC-13

Admin dapat menambahkan video dengan sumber YouTube.

AC-14

Admin dapat menambahkan video dengan sumber Google Drive.

AC-15

Admin dapat memasukkan judul, thumbnail, deskripsi, dan link Google Drive.

AC-16

Video yang belum dipublikasikan tidak tampil pada website publik.

AC-17

Ketika pengunjung menekan tombol Lihat Video pada video Google Drive, sistem membuka link Google Drive yang sesuai.

AC-18

Video Google Drive dapat dibuka pada tab baru.
