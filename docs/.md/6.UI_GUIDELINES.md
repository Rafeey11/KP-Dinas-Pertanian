# UI_GUIDELINES.md
## CWS Penyuluh
### Scope: Pengunjung / Website Publik

## 1. Tujuan Dokumen

Dokumen ini menjadi aturan implementasi UI website publik CWS Penyuluh.

Seluruh tampilan Pengunjung wajib mengikuti desain Figma yang telah disediakan.

Implementasi frontend harus memiliki tingkat kesesuaian visual setinggi mungkin dengan desain Figma.

Tidak diperbolehkan melakukan redesign.

Tidak diperbolehkan membuat interpretasi desain sendiri.

Tidak diperbolehkan menambahkan komponen baru yang tidak terdapat pada desain tanpa instruksi khusus.

Tidak diperbolehkan mengubah struktur layout hanya karena developer atau AI menganggap desain lain lebih baik.


## 2. Source of Truth

Urutan sumber kebenaran UI:

1. Figma CWS Penyuluh
2. Screenshot atau referensi desain dari Figma
3. UI_GUIDELINES.md
4. Implementasi Laravel

Jika implementasi berbeda dengan Figma, maka implementasi harus diperbaiki.

Figma selalu menjadi referensi visual utama.

# 48. Placeholder Data

Data pada Figma dapat digunakan sebagai placeholder selama development awal.

Setelah database tersedia, ganti dengan data dinamis tanpa mengubah tampilan.


# 49. Image Handling

Foto harus mempertahankan layout Figma.

Gunakan:

object-fit: cover

overflow: hidden


Jika gambar tidak tersedia, gunakan fallback image yang tetap mempertahankan dimensi card.


# 50. Content Overflow

Jika data dari database lebih panjang dari contoh Figma:

Jangan merusak card.

Gunakan line clamp jika desain card membutuhkan ringkasan.

Detail lengkap ditampilkan pada halaman detail.


# 51. Loading State

Loading tidak boleh mengubah layout secara drastis.

Gunakan loading indicator atau skeleton yang mengikuti dimensi komponen.


# 52. Empty State

Jika data kosong, tampilkan empty state sederhana.

Jangan membuat section tambahan yang berbeda dari visual system.


# 53. Error State

Error message harus konsisten dengan desain.

404

500
