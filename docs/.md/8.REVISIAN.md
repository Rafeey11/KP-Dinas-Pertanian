# 6. Admin CWS

Admin CWS merupakan role dengan kewenangan tertinggi.

Admin CWS memiliki akses ke seluruh sistem.


## 6.1 Hak Akses Admin CWS

Admin CWS dapat:

- Mengelola seluruh BPP.
- Mengelola seluruh penyuluh.
- Membuat akun BPP.
- Membuat akun Admin Tim Kerja.
- Mengubah akun.
- Menonaktifkan akun.
- Reset password.
- Mengatur role.
- Menentukan wilayah binaan Admin Tim Kerja.
- Melihat seluruh laporan.
- Memvalidasi seluruh laporan.
- Meminta revisi laporan.
- Menolak laporan.
- Melihat seluruh berita.
- Menyetujui berita.
- Menolak berita.
- Mempublikasikan berita.
- Mengubah status berita.
- Mengelola video.
- Mengelola Bank SOP.
- Mengelola konten website.
- Melihat monitoring seluruh BPP.
- Melakukan export data.
- Mengakses audit log.
- Mengambil alih proses yang dilakukan Admin Tim Kerja.


# 7. Admin Tim Kerja

Admin Tim Kerja merupakan administrator di bawah Admin CWS.

Admin Tim Kerja memiliki wilayah binaan berupa satu atau beberapa BPP.

Wilayah binaan ditentukan oleh Admin CWS.


## 7.1 Pembuatan Akun

Akun Admin Tim Kerja hanya dapat dibuat oleh Admin CWS.

Admin Tim Kerja tidak dapat melakukan registrasi sendiri.


## 7.2 Penentuan Wilayah

Admin CWS dapat menentukan BPP mana saja yang berada di bawah Admin Tim Kerja.

Contoh:

Admin Tim Kerja A:

- BPP Garut Kota.
- BPP Tarogong Kidul.
- BPP Tarogong Kaler.

Admin Tim Kerja B:

- BPP Banyuresmi.
- BPP Leles.
- BPP Kadungora.


## 7.3 Hak Akses Admin Tim Kerja

Admin Tim Kerja dapat:

- Login.
- Mengakses Dashboard Tim Kerja.
- Melihat BPP binaannya.
- Melihat penyuluh dari BPP binaannya.
- Melihat progress laporan.
- Melihat penyuluh yang sudah mengirim.
- Melihat penyuluh yang belum mengirim.
- Membuka laporan BPP binaannya.
- Menyetujui laporan BPP binaannya.
- Meminta revisi laporan BPP binaannya.
- Menolak laporan BPP binaannya.
- Melihat berita BPP binaannya.
- Menyetujui berita.
- Menolak berita.
- Mempublikasikan berita.
- Melihat riwayat laporan.
- Melihat Bank SOP yang berkaitan dengan wilayah binaannya.
- Melihat hasil pengisian Bank SOP BPP binaannya.
- Melakukan monitoring aktivitas wilayah binaannya.


## 7.4 Batasan Admin Tim Kerja

Admin Tim Kerja tidak dapat:

- Mengakses BPP di luar wilayah binaannya.
- Menentukan wilayah binaannya sendiri.
- Menambahkan BPP ke wilayah sendiri.
- Membuat Admin Tim Kerja lain.
- Membuat Admin CWS.
- Mengubah role.
- Mengakses seluruh akun sistem.
- Mengelola pengaturan global.
- Mengelola Bank SOP global.
- Mengubah target Bank SOP.
- Mengakses laporan dari BPP di luar wilayahnya.
- Mengakses berita dari BPP di luar wilayahnya.


# 8. Authorization Admin Tim Kerja

Setiap akses Admin Tim Kerja harus diperiksa berdasarkan BPP binaannya.

Tidak cukup hanya menggunakan middleware role.

Sistem harus memeriksa relationship antara:

user

dan

bpp


Contoh:

Admin Tim Kerja memiliki:

BPP ID 2

BPP ID 5

BPP ID 8


Akses:

/tim-kerja/bpp/5

Hasil:

Diizinkan.


Akses:

/tim-kerja/bpp/7

Hasil:

403 Forbidden.
